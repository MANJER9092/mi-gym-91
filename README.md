# Mi Gym 90 V8 — Realista

Versión preparada para GitHub Pages.

## Qué cambió
- Se eliminaron las figuras de palitos/siluetas como gráficos principales.
- Las tarjetas de ejercicios usan fotografías realistas de gimnasio almacenadas localmente.
- Cada ejercicio mantiene el formato **POSICIÓN INICIAL → POSICIÓN FINAL**.
- Se conserva la rutina de 4 días, registro de series, RIR, peso, repeticiones y cronómetro.
- PWA instalable en iPhone.

## Publicación
Sube/reemplaza el contenido de esta carpeta en la rama `main` del repositorio `mi-gym-91`.
En GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
