# Mi Gym 90

Aplicación web estática para iPhone, diseñada para la rutina de 4 días.

## Publicación con GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `mi-gym-90`.
2. Sube **todos los archivos de esta carpeta** a la raíz del repositorio.
3. En GitHub: **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)` y pulsa **Save**.
5. GitHub Pages publicará la web en una dirección del tipo:
   `https://TU-USUARIO.github.io/mi-gym-90/`
6. En el iPhone, abre esa dirección con Safari.
7. Pulsa **Compartir → Agregar a Inicio → Abrir como app web → Agregar**.

GitHub Pages publica archivos HTML/CSS/JavaScript estáticos directamente desde un repositorio. La publicación puede tardar unos minutos.

## Archivos
- `index.html`: aplicación completa.
- `manifest.json`: configuración de app web.
- `sw.js`: caché para uso offline después de la primera carga.
- `icon-180.png`: icono para iPhone.
- `icon.svg`: icono vectorial.
- `.nojekyll`: evita procesamiento innecesario de Jekyll.
